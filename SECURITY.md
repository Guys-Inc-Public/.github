# Security Policy

## Reporting a vulnerability

We take security seriously. If you discover a vulnerability in any Guys Inc
project, please report it responsibly.

**Preferred:** use GitHub's [private vulnerability reporting][gh-report] on the
affected repository (Security tab → *Report a vulnerability*).

**Alternatively:** email **CJ@guysinc.org** with:

- A description of the issue and its impact
- Steps to reproduce (proof-of-concept if possible)
- Any suggested remediation

Please **do not** open a public issue for security reports.

## What to expect

- We aim to acknowledge reports within a few business days.
- We'll keep you updated as we investigate and work on a fix.
- We're happy to credit you once the issue is resolved, unless you prefer to
  remain anonymous.

[gh-report]: https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability
