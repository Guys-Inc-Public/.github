# Contributing to Guys Inc projects

Thanks for your interest in contributing! These guidelines apply across all
public repositories in the [Guys Inc](https://github.com/Guys-Inc-Public)
organization.

## Ways to contribute

- **Report a bug** — open an issue using the Bug Report template
- **Request a feature** — open an issue using the Feature Request template
- **Submit a fix or improvement** — open a pull request

## Pull request workflow

1. **Fork** the repository and create your branch from `main`.
2. Make your change, keeping it focused — one logical change per PR.
3. Match the existing code style; add or update tests where it makes sense.
4. Ensure the build and any checks pass locally.
5. Open a pull request with a clear description of **what** changed and **why**.

## Commit messages

Write clear, imperative commit subjects (e.g. `Fix race in deploy webhook`).
Reference issues where relevant with `#123`.

## Code of Conduct

By participating, you agree to uphold our
[Code of Conduct](./CODE_OF_CONDUCT.md).

## Questions

Open a discussion or issue on the relevant repository, or reach out at
**CJ@guysinc.org**.
