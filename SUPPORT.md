# Support

Thanks for using a Guys Inc project. Here is the fastest route to an answer.

## Where to ask

| You have | Go to |
|---|---|
| A question about how to use something | The repository's **Discussions** tab → *Q&A* |
| An idea, or feedback that is not a defect | **Discussions** → *Ideas* |
| Something reproducibly broken | **Issues**, using the Bug Report form |
| A security vulnerability | **Do not open an issue.** See [SECURITY.md](./SECURITY.md) |
| Something else entirely | **CJ@guysinc.org** |

## Getting a useful answer faster

Include the version or commit you are on, what you expected, what happened
instead, and the exact command or steps. If there is an error, paste the text
rather than describing it — the wording is usually the fastest route to the
cause.

## What to expect

These are maintained projects, not products with a support contract. Issues and
discussions are read, and most get a reply within a few days. A bug with a clear
reproduction gets attention much sooner than one without.

Pull requests are welcome. See [CONTRIBUTING.md](./CONTRIBUTING.md).
